Зачем нужен MTProto

Это вход пользовательской Telegram-сессией через Telethon. MTProto нужен только для аналитики каналов и чатов, где Bot API не отдает достаточно данных.

MTProto не нужен для добавления Bot API токенов, проверки `getMe`, обычной отправки сообщений и работы вкладки «Боты».

  1. Введи телефон в международном формате и нажми «Запросить код».
  2. Код придет в Telegram. Вставь его в поле «Код» и подтверди.
  3. Если включена 2FA, введи пароль Telegram Cloud Password.

Важно: в локальной сети админка без авторизации, поэтому любой клиент с доступом к ней сможет пользоваться сохраненной MTProto-сессией через функции приложения.
