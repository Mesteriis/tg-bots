Как правильно писать шаблоны

Шаблон хранится под коротким tag и затем вызывается из REST, MCP или формы «Отправка по шаблону». Текст пишется обычным сообщением Telegram, а переменные вставляются через двойные фигурные скобки.

  • Плейсхолдеры: {{name}}, {{order_id}}, {{env}}. Имя начинается с буквы или подчеркивания.
  • Встроенные значения не нужно передавать вручную: {{date}}, {{time}}, {{datetime}}.
  • Если выбран HTML или MarkdownV2, Telegram-разметка остается на твоей ответственности. Кнопка ниже проверяет синтаксис переменных и пробный рендер.
  • Для проверки результата добавь JSON с тестовыми переменными, например { "name": "api", "env": "prod" }.

Зачем нужен MTProto

Это вход пользовательской Telegram-сессией через Telethon. Она нужна только для аналитики каналов и чатов, где Bot API не отдает достаточно данных.

  1. Введи телефон в международном формате и нажми «Запросить код».
  2. Код придет в Telegram. Вставь его в поле «Код» и подтверди.
  3. Если включена 2FA, введи пароль Telegram Cloud Password.

Важно: в локальной сети админка без авторизации, поэтому любой клиент с доступом к ней сможет пользоваться сохраненной MTProto-сессией через функции приложения.

Шаг 1: запрос кода

Номер используется только для старта Telethon-сессии и запроса кода у Telegram.

Шаг 2: подтверждение кода

Код приходит в Telegram-приложение аккаунта, который указан на первом шаге.

Шаг 3: пароль 2FA

Заполняется только если Telegram требует облачный пароль для завершения входа.
